# 📊 Layoffs Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard built using a cleaned layoffs dataset. The dashboard helps analyze layoff trends across companies, industries, countries, funding stages, and time periods through interactive visualizations.

---

## 🎯 Objectives

- Analyze global layoff trends.
- Compare layoffs across companies, industries, and countries.
- Identify monthly and yearly layoff patterns.
- Build an interactive dashboard for easy data exploration.

---

## 🛠️ Tools Used

- Power BI
- SQL (MySQL)
- Microsoft Excel

---

## 📂 Dataset

The dataset was cleaned and prepared in MySQL before being imported into Power BI.

Data Cleaning included:
- Removing duplicate records
- Standardizing inconsistent values
- Handling missing values
- Converting date formats
- Preparing an analysis-ready dataset

---

## 📈 Dashboard Features

- KPI Cards
  - Total Layoffs
  - Total Companies
  - Total Industries
  - Total Countries

- Interactive Slicers
  - Year
  - Company
  - Industry
  - Country
  - Funding Stage

- Visualizations
  - Monthly Layoff Trend
  - Top Companies by Layoffs
  - Layoffs by Country
  - Layoffs by Industry
  - Layoffs by Funding Stage
  - Year-wise Layoff Analysis

---

## 💡 Key Insights

- Identified companies with the highest layoffs.
- Compared layoffs across different industries.
- Analyzed yearly and monthly layoff trends.
- Explored the impact of funding stages on layoffs.
- Visualized global layoff distribution by country.
